# WeeklyMenus

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Générer les menus d'une semaine complète à partir d'une collection gérée dans l'application, à raison d'un repas par jour.

## Capabilities and Constraints

- Gérer les menus et leurs ingrédients.
- Composer un planning de sept repas à partir de la collection.
- Créer directement une interface web ; les données sont enregistrées dans SQLite par un backend Python local.
- Public précis et liste de courses : décisions ouvertes.

## Operating Context

Interface en français. Le serveur Python sert l’interface et son API locale.
